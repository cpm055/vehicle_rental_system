🚗 Smart Vehicle Rent
Smart Vehicle Rent is a modern web application designed to simplify the process of renting vehicles while promoting eco-conscious travel. Our mission is to make transportation more accessible, organized, and environmentally friendly through smart systems.

🌍 Why We Built This
We built this platform to help people:

Easily rent vehicles online without hassle.

Encourage the use of eco-friendly transportation.

Reduce road congestion by promoting shared mobility.

Create a smarter, more sustainable urban mobility experience.

🛠️ Features
📝 User-Friendly Booking System – Rent a vehicle in just a few clicks.

🚘 Real-Time Vehicle Availability – See which cars, bikes, or vans are ready for rent.

🔒 Secure User Authentication – Protected access for users and admins.

🌱 Eco-Friendly Focus – Highlight and promote electric and low-emission vehicles.

📊 Admin Dashboard – Manage rentals, vehicles, and users with full control.

🧠 Tech Stack
Frontend: React.js (Vite / CRA)

Backend: Java Spring Boot (REST API)

Database: MongoDB / MySQL (based on your setup)

Authentication: JWT / Spring Security

💡 Future Scope
Integration with Google Maps for pickup/drop locations.

Implementing payment gateways for hassle-free online transactions.

Adding AI suggestions for the most suitable vehicle based on trip plans.
